# 兼容性与已知问题

## 支持环境

目标环境为 Windows、PSCAD 4.6.2 x64、GFortran 4.6.2 和官方 mhrc.automation 1.2.4。Python 包要求 Python 3.11 或以上版本；编译目录和工程名称使用 ASCII。

CLI 和 MCP 共用一个工作线程、持久后台会话和任务队列，默认串行执行。PSCAD 4.6.2 未实现部分自动化命令，包括 get-port-location、is-busy 和 set-volley，驱动使用相应替代路径。

工况名和运行标签使用 ASCII 名称，可包含字母、数字、下划线、连字符和内部点号，不接受路径或结尾点号。工况、运行和基线的派生目录限定在各自根目录内。CLI、MCP 和任务接口在未指定超时时使用配置中的构建/运行时限。

画布适配处理页面尺寸和对象范围；电气模型、控制策略和任务指标由使用者或执行 AI 确定。构建完成后仍需根据数值结果判断模型是否满足要求。

## 验证范围

全新机器上从依赖安装、下载、CHM 提取到 PSCAD 运行的完整流程尚未验证。

已有工程的检查首次需要元件索引时，会从已配置的 master 库生成索引，无需手动运行 palette 命令。几何检查与建模使用相同的0～7方向变换。

阻塞调用由 ActivityGuard 和 force_disconnect 处理：监测任务进展及文件活动，停滞时终止驱动启动的进程并断开通信。完整的原生停滞处理仍需在独立安装环境验证。

## 截图、本地服务与 CSV

截图是可选功能，CLI `run` 默认关闭，附加 `--snapshot` 才请求截图；`--no-snap` 保留兼容。保存前检查剪贴板已更新且所有者属于本次 PSCAD 进程，并在持有剪贴板锁时读取位图。复制失败、来源无法确认或格式不支持时报告错误，不保存图片，也不清空剪贴板。独立桌面下 PSCAD 4.6.2 的实际剪贴板所有者行为仍需原生验证，来源检查不通过时可继续使用数值结果。

本地任务服务仅监听回环地址，CLI 和 MCP 自动使用随机 Bearer 令牌，无需手填。令牌按端口保存在当前 Windows 用户的 `%LOCALAPPDATA%/pscad-ai/worker-<port>.token`，不放入仓库或工作产物。服务在读取正文和派发任务前拒绝无效令牌、带 Origin 的请求、不匹配的 Host 及非 JSON 请求。此机制依赖用户目录的操作系统权限，不能隔离已有该用户文件访问权限的进程。升级后需重启本项目的任务服务使新代码生效；`op:close` 只关闭 PSCAD 会话，不退出服务进程。

CSV 导出会为可能被电子表格解释成公式的通道名加前导单引号，原本以单引号开头的名称也加一个，避免名称合并。含逗号或双引号的名称使用标准 CSV 引用。该处理覆盖完整导出、选通道导出、运行归档和比较报告；`.inf/.out`、内存查询中的通道名及数值不变。比较使用 CSV 中的完整列名，因此旧 CSV 与新转义 CSV 中的特殊名称需统一后再比较。

## 结果比较

基线比较要求两份结果有相同的信号通道集合、有限样本和严格递增的时间轴。缺失通道、空数据或当前结果不能覆盖参考时间范围时，比较报错，不按通过处理。

`bit_exact` 表示读取后的原始时间轴和各同名通道的浮点表示一致，不表示CSV文本字节相同。不同时间轴可在覆盖范围内线性插值；插值后最多判为 `numerical`，超出绝对与相对容差则为 `changed`。参考全零时仍按绝对容差判定，未定义的相对误差显示为 `n/a`。

## 工程与客户端权限

工具会读写工程并启动本机程序，自定义组件可以包含 Fortran 代码，应使用可信来源的工程。MCP 查询结果会返回给接入的 AI 客户端；使用云端模型时，按该客户端的数据处理方式选择适合提供的资料。
