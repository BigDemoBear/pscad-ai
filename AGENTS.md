# Working with this checkout

For PSCAD tasks, read `skills/pscad-simulation/SKILL.md` and use this checkout's `.venv`.
Set the process-local `PSCAD_AI_CONFIG` to this checkout's `config.yaml` when invoking its tools.
If setup is missing, follow the quick start in README.md. Do not reuse or modify another project's environment or task service.
The `work/` directory and `mcp.local.json` are private local output, not source to commit.
